ni_bridge.js — offline harness

Mock pcbdata / config / settings plus a stub populateBomTable(), so the external grouping module can be exercised without the warehouse system. Open this file directly in a browser — no server, no build step. The initial REST fetch is expected to fail here; that is the degradation scenario. Everything else is driven from the buttons below or from NIBridgeDebug.grouping in the console.

Grouping activates only when template_id is in the query string. Reload with ?template_id=harness.
