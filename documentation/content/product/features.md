# Features

## Warehouse

- Component catalog with parameters, documents, tags, and categories
- Hierarchical locations and stock packets (batches)
- Supplier relations and purchase workflows
- Reservations and inventory campaigns
- Global search across components, locations, packets, and more

## Production

- Product and BOM management
- BOM notes (Markdown-friendly fields in the UI)

## Printing

- Print queues scoped by service token
- Async label render jobs for hardware drivers

## Access control

- Role-based permissions per functional area
- Superadmin bypass for administrative tasks

## Extensibility

- In-repo plugin system with extension points (see [Plugin system](../developer/plugin-system.md))
